# agmsg-viewer-addon

[English version here](README.md)

**agmsg-viewer を、agmsg アプリの中で。**
[agmsg](https://github.com/fujibee/agmsg) デスクトップアプリ（0.6.0以降）向けのアドオンペインで、選択中のチームの会話を LINE 風チャットタイムラインで表示します。作者は単体版
[agmsg-viewer](https://github.com/utenadev/agmsg-viewer) の
[utenadev](https://github.com/utenadev) です。

単体版ビューアは Go バイナリが agmsg の SQLite DB を直接読みます。このアドオンは同じ「見る」体験をアプリ内へ持ち込むもので、隔離されたアドオンペインの中で、ユーザーが許可したメッセージだけを受け取って動きます。DB アクセスなし、プログラム実行なし、agmsg の操作もできません。

## 画面のイメージ（スクリーンショット相当の説明）

単体版ビューアのチャット画面が、そのままアプリの1ペインに収まった姿です。

- 上部に白いツールバー：チーム名、メッセージ件数、**↑ Top / ↓ Bottom** ジャンプボタン、検索ボックス、送信者フィルタのドロップダウン。
- その下は見慣れたスレートブルー（`#7493c0`）のチャット背景。メッセージは古い順に並び、「Today」「Yesterday」や日付の丸い日付ピルで区切られます。
- 読み込んだ範囲の**最初の発言者**は agmsg-viewer の流儀で**右寄せ・黄緑（`#85e249`）バブル**。他のエージェントは**左寄せ**で、エージェントごとのパステルカラーのバブルと、頭文字＋固有色の丸アバターが付きます。各バブルの脇に宛先（`→ name`）と時刻（ホバーでフルタイムスタンプ）を表示。
- 長いレポートはフェード付きで折り畳まれ、**「Show all (N chars)」**ボタンで展開できます。1件の長文で会話が埋もれません。
- ステータスワードには LINE 風の**自動スタンプ**：本文に `CLEARED` を含むと `✅ CLEARED`、`BLOCKED` には `🧱 BLOCKED`、「お疲れさま」には `🍵` のスタンプチップが付きます。半分洒落、半分はスクロールしながら仕事の結末を拾うためのスキャナです。

## 機能

- **LINE 風バブル**：単体版の配置・色分けルール（最初の発言者は右・緑、他は左・エージェント別パステル）を踏襲。
- **ライブ更新**：アプリから届く新着メッセージを随時反映。一番下を見ているときだけ自動で追随スクロールします。
- **キーワード検索と送信者フィルタ**：即時適用、「showing N」件数表示付き。
- **日付区切り**と、ホバーでのフルタイムスタンプ表示。
- **長文の折り畳み**（360文字超、または8行超）。
- `CLEARED` / `BLOCKED` / お疲れさま への**自動スタンプ**。
- ライト／ダークはサンプルアドオン同様、システム設定に追随。

## インストール

1. agmsg アプリで **Settings → Add-ons → Install from GitHub** を開く。
2. `utenadev/agmsg-viewer-addon` と入力して **Install…** を押す。
3. 要求される権限（チームのメッセージ読み取り）を確認して承認する。
4. ペイン上部の **+** から **Add-on pane ▸ Chat viewer** を選択。初回は現在のチームのメッセージ読み取りを許可してください。

## 権限

| 権限 | 理由 |
| --- | --- |
| `messages:read` | これだけです。選択中チームの会話を、エージェント別カラーのチャットタイムラインとして表示し、キーワード／送信者フィルタと長文折り畳みを提供するため。 |

`files:read`、`git:read`、`network` は使いません。ペイン内には何も保存しません（サンドボックスにストレージがないこともあり）。検索語やフィルタはペインを開いている間だけ有効です。

## 制限

- アプリがペインに渡すのは**最新500件**までです。忙しいチームでは途中からの表示になり、「最初の発言者」も読み込んだ範囲の先頭の発言者を指します（単体版の tail 表示と同じ考え方）。
- あくまでビューアです。アドオンのサンドボックス設計上、メッセージ送信や agmsg の操作はできません。

## 開発

ビルド不要です。`app-panes/chat-viewer/web/` がそのままアプリにインストールされます。

```bash
# 通常のブラウザでプレビュー（キットが約1秒後にサンプルデータを流します）:
python3 -m http.server 8000 -d app-panes/chat-viewer/web
# → http://localhost:8000

# アプリのインストール時チェックと同じ検証:
node kit/agmsg-addon-check.cjs
```

アプリ実機で開発中に試す場合：**Settings → Add-ons → Developer → Load from folder…** でこのリポジトリを選び、**+** メニューからペインを開いてください。

`kit/` は [fujibee/agmsg-addon-sample](https://github.com/fujibee/agmsg-addon-sample) 経由で agmsg アプリ本体（`app/addon-kit/`）からコピーしたものです。編集せず、新しいキットが出たらそちらをコピーしてください。
